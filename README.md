# 🖥️ AmirOS

**AmirOS** is a web-based operating system simulation built with HTML, CSS, and JavaScript.

یک سیستم‌عامل تحت وب با رابط کاربری دسکتاپ و برنامه‌های کاربردی که با HTML، CSS و JavaScript ساخته شده است.

### ✨ Features | امکانات
- 🕒 Clock | ساعت
- 🎵 Music Player | موزیک پلیر
- 📝 Notepad | دفترچه یادداشت
- 🌐 Web Browser | مرورگر وب
- 🔋 Battery Status | وضعیت باتری
- 🔊 Volume Control | کنترل صدا
- 🖥️ Desktop Interface | محیط دسکتاپ

### 🛠️ Technologies | تکنولوژی‌ها
HTML5 · CSS3 · JavaScript
